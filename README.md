# Restaurant Seating Console

A C++ console program for managing restaurant table reservations.

## Features

- Makes reservations with best-fit table suggestions
- Cancesl existing reservations
- Checks available tables by hour
- Displays a table’s full schedule
- Generates hourly occupancy reports

## Tech Used

- C++
- Console input/output
- Vectors
- Functions


## Build

```bash
g++ src/main.cpp -o restaurant.exe
```

# Run(on windows comand prompt may be differnt depending on your terminal)

```bash
.\restaurant.exe
```
